# netbox-cross-journal

Генерує друкований/Excel крос-журнал (інвентар пристроїв, кабелі даних, кабелі живлення) для
шафи (Rack), локації (Location) або сайту (Site) — прямо з даних NetBox, без ручного ведення
окремого документа.

## Можливості

- Кнопка "Крос-журнал" на сторінках Rack / Location / Site (панель праворуч, у стилі
  [netbox-labels](https://github.com/N34AY/netbox-labels)).
- **Переглянути** — друкований HTML-звіт (список пристроїв, кабелі даних, кабелі живлення).
- **Завантажити Excel** — той самий звіт у .xlsx, генерується **на сервері** (openpyxl), а не
  в браузері — важливо для шаф/локацій з великою кількістю пристроїв.
- **Схема топології** (Plugins → Крос-журнал → Схема топології) — одна інтерактивна схема
  всього NetBox (ELK.js): кожен пристрій — окремий блок з підписаними портами, кабелі
  прокладаються ортогонально без накладань. Кнопка на сторінках Rack / Location / Site /
  Region відкриває ту саму схему з уже вибраним фільтром (`?rack=12`), тобто схема — це
  конструктор фільтрів. Фільтри: тип з'єднання (дані / живлення / консоль), пристрої, регіони,
  сайти, локації (разом з дочірніми), шафи, типи пристроїв, ролі, виробники, теги. Сусіди
  відфільтрованих пристроїв показуються крізь патч-панелі та розподільчі коробки (PortMapping).
  Масштабування й панорамування; друк усієї схеми на одному аркуші A4–A0 та експорт у SVG.
  Стан фільтрів зберігається в URL — посилання можна переслати.
- **Збережені макети** (Plugins → Крос-журнал → Збережені макети) — спільні для всіх
  користувачів з відповідними правами. Макет зберігає фільтри і, в ручному режимі, розташування
  карток; пристрої та кабелі завжди читаються з NetBox наживо (новий кабель просто з'являється,
  новий пристрій ставиться праворуч з пунктирною рамкою). Режими:
  - **Автоматично** — розкладку робить ELK;
  - **Вручну** — картки стоять там, куди їх перетягнули (перетягування картки в автоматичному
    режимі саме перемикає у ручний). Кабелі: «в обхід карток» (власний ортогональний
    маршрутизатор, `topology_router.js`) або «ELK інтерактивно» (ELK використовує позиції
    лише як підказку й ставить картки в колонки).
- Локація рахується рекурсивно (включно з усіма дочірніми локаціями).
- Живі, редаговані з інтерфейсу налаштування (Plugins → Крос-журнал → Налаштування):
  - назва організації для заголовку звіту;
  - які розділи включати (кабелі даних / кабелі живлення / теги / IP / серійні номери /
    коментарі);
  - розкладка Excel-файлу (окремі аркуші чи один спільний);
  - які статуси пристроїв виключати зі звіту (за замовчуванням — «виведені з експлуатації»).
- Повна українська локалізація інтерфейсу.

## Встановлення

```bash
pip install git+https://github.com/N34AY/netbox-cross-journal.git
```

`configuration.py`:

```python
PLUGINS = [
    "netbox_cross_journal",
]
```

Плагін містить статичні файли (схема топології), тож після встановлення/оновлення:

```bash
python manage.py collectstatic --no-input
```

Все інше конфігурується з інтерфейсу NetBox (Plugins → Крос-журнал → Налаштування) — нічого
додавати в `PLUGINS_CONFIG` не потрібно.

## Локальна розробка

```bash
docker compose up -d --build
docker compose exec netbox /opt/netbox/venv/bin/python /opt/netbox/netbox/manage.py migrate
```

NetBox доступний на `http://localhost:8001/` (логін/пароль: `admin`/`admin`).
