# netbox-cross-journal

Генерує друкований/Excel крос-журнал (інвентар пристроїв, кабелі даних, кабелі живлення) для
шафи (Rack), локації (Location) або сайту (Site) — прямо з даних NetBox, без ручного ведення
окремого документа.

## Можливості

- Кнопка "Крос-журнал" на сторінках Rack / Location / Site (панель праворуч, у стилі
  [netbox-labels](https://github.com/N34AY/netbox-labels)).
- **Переглянути** — друкований HTML-звіт (список пристроїв, кабелі даних, кабелі живлення).
- **Завантажити Excel** — той самий звіт у .xlsx, генерується **на сервері** (openpyxl), а не
  в браузері — важливо для шаф/локацій з великою кількістю пристроїв.
- Локація рахується рекурсивно (включно з усіма дочірніми локаціями).
- Живі, редаговані з інтерфейсу налаштування (Plugins → Крос-журнал → Налаштування):
  - назва організації для заголовку звіту;
  - які розділи включати (кабелі даних / кабелі живлення / теги / IP / серійні номери /
    коментарі);
  - розкладка Excel-файлу (окремі аркуші чи один спільний);
  - які статуси пристроїв виключати зі звіту (за замовчуванням — «виведені з експлуатації»).
- Повна українська локалізація інтерфейсу.

## Встановлення

```bash
pip install git+https://github.com/N34AY/netbox-cross-journal.git
```

`configuration.py`:

```python
PLUGINS = [
    "netbox_cross_journal",
]
```

Все інше конфігурується з інтерфейсу NetBox (Plugins → Крос-журнал → Налаштування) — нічого
додавати в `PLUGINS_CONFIG` не потрібно.

## Локальна розробка

```bash
docker compose up -d --build
docker compose exec netbox /opt/netbox/venv/bin/python /opt/netbox/netbox/manage.py migrate
```

NetBox доступний на `http://localhost:8001/` (логін/пароль: `admin`/`admin`).
